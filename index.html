Human Brain Fingerprinting
Over the past few decades, neuroscientists have investigated whether patterns of brain activity are stable and distinctive enough to uniquely identify individuals, much like a biological fingerprint. If so, such patterns could deepen our understanding of how brain organization varies across people and how those differences relate to behavior, cognition, and mental health. The applications to this range from aiding in the early detection of neurological or psychiatric conditions to enabling personalized treatment based on brain profiles. Using functional MRI data from 414 participants, I developed a novel brain fingerprinting framework based on high-dimensional data decomposition techniques. My contributions to this project resulted in a first-author publication, available here, as well as presentations at international conferences. A sample of the code used to generate the results for this project is available in this Github repository.

Object Classification from Tactile Sensing
Motivated by the need for reliable touch-based perception in soft robotics applications where visual information may be limited or unreliable, this project focused on classifying objects using tactile data collected from substrates embedded with piezoelectric sensors. I developed a sparse tactile sensing framework to identify the most informative sensors for object recognition, enabling accurate classification while minimizing hardware complexity and cost. The object classification pipeline that I implemented achieves about 90% accuracy while reducing the number of required sensors by 60%. The results demonstrate how efficient sensor selection and signal processing can improve tactile recognition systems while keeping them scalable and resource-efficient.

PepsiCo MPG Optimization (Senior Design Project)
PepsiCo's fleet engineers had historically relied on visual trend analysis and expert judgment to guide decisions about purchasing and retiring tractors. My team was tasked with designing a more rigorous, data-driven approach to shift this process from qualitative to quantitative decision-making, with the goals of improving mileage per gallon (MPG), reducing emissions, and supporting PepsiCo's Pep+ sustainability initiative. After conducting exploratory data analysis, we performed feature engineering (including one-hot encoding categorical variables, standardizing numerical features, and imputing missing values) and trained a Random Forest regressor to identify key factors influencing MPG across the fleet. We translated the model's insights into actionable business recommendations to optimize fleet allocation, projecting up to a 20% reduction in operating costs while supporting PepsiCo's sustainability goals.

Personal Finance Dashboard
This personal project was developed to help me better manage my spending through an automated, data-driven workflow. I built an end-to-end pipeline using Power Automate to parse incoming credit card transaction emails, extract key information (date, merchant, and amount), and load the data into a centralized Excel dataset. I then created a merchant-classification system using Excel (XLOOKUP and a custom mapping table) to automatically assign each transaction to categories such as groceries, dining, and shopping. To support ongoing tracking, I implemented daily refreshes so the dataset and visuals would update automatically as new transactions arrived. Finally, I designed an interactive, mobile Power BI dashboard to analyze spending trends over time, enabling dynamic filtering by category, merchant, and period. This tool has been highly effective in increasing my awareness of spending patterns and supporting more intentional financial decisions.
